# Product Overview

**Canonical Pages** is a WordPress plugin that allows users to quickly add and customize canonical meta tags for pages and posts.

## Core Functionality
- Adds canonical URL meta tags to WordPress pages and posts
- Provides custom URL override capability through the block editor
- Integrates with popular SEO plugins (Yoast SEO, Rank Math, All in One SEO, Slim SEO)
- Supports WordPress native canonical URL system

## Key Features
- Toggle canonical tags on/off per page/post
- Choose between "this page" URL or custom URL
- Block editor integration for easy management
- Compatible with major SEO plugins via filter hooks

## Target Users
WordPress site administrators and content creators who need fine-grained control over canonical URLs for SEO purposes.
